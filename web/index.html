Local-first business intelligence: reports and dashboards over your own data files.

Run a report in your browser

Pick a sample, or drop a .dvz report together with the data files it reads (CSV, Parquet or JSON). The report is compiled to SQL by the same Rust code as the command line tool, and the queries run in DuckDB-Wasm. Nothing leaves your computer.
